# High-Tech School Fight Script

This script provides various features for a high-tech school fight experience in Roblox. It includes a style changer, compound V abilities, auto farm functionality, and noclip mode. These features are designed to enhance the gameplay experience in a school setting.

## Install

1. Place the `main.lua` script in the `ServerScriptService`.
2. Place the `StyleChanger.lua`, `CompoundV.lua`, `AutoFarm.lua`, and `Noclip.lua` scripts in the same folder as `main.lua`.

## Use

- **Style Changer**: Press F1 or F2 to change styles.
- **Compound V**: Press F3 to activate Compound V.
- **Auto Farm**: Press F4 to start auto farming and F5 to stop.
- **Noclip**: Press F6 to toggle noclip.
